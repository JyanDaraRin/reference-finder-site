
# Reference Finder

A personal music reference discovery and
audio analysis project.

Reference Finder combines local audio
measurements with external music metadata
to help identify musical similarities.

## Metadata Sources

- [GetSongBPM](https://getsongbpm.com/)
  — BPM, musical key and time signature
  reference data.

- [Last.fm](https://www.last.fm/)
  — community music tags and discovery.

External metadata is treated as reference
information, not verified musical fact.

Reference Finder is an independent project.
